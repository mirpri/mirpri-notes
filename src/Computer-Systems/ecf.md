# Exeptional Control Flow

## 正常控制流 vs 异常控制流

- **正常控制流**：指程序按照设定好的流程，一条一条地执行指令 。在此期间，程序计数器（如 x86-64 中的 `RIP`）根据当前指令的长度或转移指令（如 `CALL`、`RET`、跳转指令）自动发生变化 。    
- **异常控制流 (ECF)**：指用户进程的正常控制流被打断，系统转去执行另外一段程序（即异常/中断处理程序）的现象 。它是现代计算机系统实现多任务、交互和错误处理的基石。

## 中断vs异常

根据事件触发的来源和与当前指令的关系，通常将其划分为**外部中断**和**内部中断（异常）** ：

```
                          ┌── 不可屏蔽中断 (NMI)
              ┌─ 外部中断 ─┤
              │  (异步事件)└── 可屏蔽中断 (INTR)
  中断源分类 ──┤
              │           ┌── 故障 (Faults)
              └─ 内部中断 ─┼── 陷阱 (Traps)
                 (同步异常)└── 中止 (Aborts)
```

### 中断

由 **CPU 外部设备**（IO设备） 触发的、与当前正在执行的指令无关的**异步事件** 。
    
中断处理程序执行完后，一律返回到**被中断的断点处**继续执行 。
    
**分类** ：
- **不可屏蔽中断 (NMI)**：通常是非常紧急的硬件故障，CPU在执行完当前指令后必须无条件相应，如电源掉电、存储器出错或总线奇偶校验错等灾难性硬件故障。
- **可屏蔽中断 (INTR)**：通过可屏蔽中断请求线INTR向CPU进行请求的的中断，主要来自IO设备的中断请求，可以通过设置标志寄存器的中断允许标志 `IF` 来控制（`STI` 指令置 `IF=1` 开启中断；`CLI` 指令置 `IF=0` 关闭中断），如来自键盘、鼠标、时钟等外设的请求 。


### 异常

处理器在其内部检测到的，与当前正在执行的指令相关的**同步事件** 。
    
- **Intel CPU 中的三类异常** ：
    
- **故障 (Faults)**：在引起异常的指令**之前或指令执行期间**产生 。通常**可以被纠正**。处理完后，CPU 会**重新执行**引起故障的指令（如：除法出错、数据访问越界、缺页故障） 。
- **陷阱 (Traps)**：在执行引起异常的指令**之后**产生并通知系统 。处理完后，回到该指令的**下一条指令**继续执行 。
	- **软中断**（程序中有意写入的 `INT n` 指令）
	- **单步异常**（标志位 `TF=1` 时，每执行完一条指令便产生一次异常） 
	- **断点异常**（调试器在代码中插入的 `INT 3` 指令）
- **中止 (Aborts)**：系统出现**严重硬件故障或严重不一致**时通知系统 。引起中止的指令**无法确定**，且程序**不能恢复执行**，系统通常会直接重新启动或终止进程 。（如硬件故障、系统表中出现非法值或不一致的值）
        
## 处理过程

当CPU在处理当前指令时检测到异常事件，或收到中断请求信号，CPU 决定响应中断或异常后，保存断点和状态，通过中断描述符表找到对应的处理程序地址，转到处理程序去执行。处理完毕后，若可恢复，继续执行当前程序；若不可恢复，则终止用户进程。
## 中断描述符表

中断类型码与对应的中断处理程序之间的连接表，按中断类型码存放存放中断处理程序相关信息（入口地址、类别、权限等）的表

门 ：指中断和异常处理程序的入口地址等信息
- **任务门**：执行处理程序时将发生任务转移 。        
- **中断门**：主要用于处理外部中断 。        
- **陷阱门**：主要用于处理异常 。

实方式与保护方式
- **实方式（实模式）**：称为**中断矢量表** 。大小固定为 **1KB**，固定从物理地址 `0` 开始存放 。每个表项 4 字节，保存处理程序的 `CS` 和 `IP` 。    
- **保护方式（保护模式）**：称为**中断描述符表 (IDT)** 。按照统一风格定义，每个表项占 **8 字节**，256 个表项共占用 **2KB** 空间 。由 `IDTR` 寄存器决定其在主存中的起始物理地址 。通过中断号映射到段描述符，最终找到代码段的入口点 。
## 优先级关系

当多个中断/异常同时发生时，CPU 遵循以下优先级由高到低的顺序响应 ：

1. 最高：除调试故障以外的异常    
2. 异常指令（`INTO`、`INT n`、`INT 3`）    
3. 对当前指令的调试异常    
4. 对下条指令的调试异常    
5. 不可屏蔽中断 (NMI)    
6. 最低：可屏蔽中断 (INTR)
